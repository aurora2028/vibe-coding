## ✨项目介绍
面向用户的穿搭偏好收集与服装推荐原型。
用户填写穿搭偏好（裙长、场景、颜色、版型），系统根据偏好打分排序做商品推荐；支持正向收藏、负反馈屏蔽，用户数据全部保存在浏览器 localStorage，**无后端、无付费API**。

### 核心功能
- 用户偏好配置：裙长、使用场景、颜色、版型、预算、品牌喜好、排斥项
- 简易推荐引擎：多维度偏好打分，对商品进行排序
- 正向反馈：收藏商品，提取喜爱特征更新个人偏好
- 负向反馈：屏蔽风格、颜色、品牌，抑制后续推荐
- 响应式布局，适配PC与移动端
- 本地持久化存储，刷新页面偏好不会丢失

## 🛠技术栈
HTML + CSS + Vanilla JavaScript，零第三方框架。
