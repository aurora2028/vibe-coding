## MindfulSelect · 穿搭偏好推荐

一个基于用户主动偏好、收藏反馈和“不感兴趣”反馈的女装推荐原型。

核心体验：

- 从模糊搜索进入“Help Me Choose”选款流程；
- 保存裙长、场合、颜色和版型偏好；
- 收藏商品时补充喜欢的特征；
- 用不同负反馈减少重复、不合适商品；
